# Встреча 360

**Встреча 360** — Telegram-бот для автоматической расшифровки и оценки деловых встреч.
Пользователь отправляет видео или аудио, а бот разделяет реплики участников, добавляет
тайм-коды, формирует текстовый транскрипт и проверяет разговор по 11 критериям.
Результат и технический статус обработки сохраняются в PostgreSQL.

## Что умеет бот

- принимает видео и аудио через Telegram;
- распознаёт несколько говорящих с помощью AssemblyAI Speaker Diarization;
- формирует транскрипцию вида `[00:42] Спикер A: ...`;
- оценивает встречу по 11 критериям из `prompt.md`;
- показывает балл, доказательства, решения, задачи, сроки и рекомендации;
- отправляет транскрипцию отдельным `.txt`-файлом;
- сохраняет транскрипцию, аудит, число спикеров и статус в PostgreSQL;
- запускается в Docker и автоматически перезапускается при сбое.

## Логика обработки

```text
Telegram → проверка файла → AssemblyAI → транскрипция со спикерами
         → OpenAI → аудит встречи → Telegram + PostgreSQL
```

Telegram — только интерфейс. В дальнейшем вместо него можно подключить сайт,
другое приложение или корпоративный мессенджер.

## Быстрый запуск через Docker

1. Создайте файл `.env` из примера:

```bash
cp .env.example .env
```

2. Заполните в `.env` как минимум:

```env
TELEGRAM_BOT_TOKEN=...
ASSEMBLYAI_API_KEY=...
OPENAI_API_KEY=...
POSTGRES_PASSWORD=замените_на_сложный_пароль
```

3. Соберите и запустите проект:

```bash
docker compose up --build -d
```

4. Проверьте состояние и журнал:

```bash
docker compose ps
docker compose logs -f bot
```

5. Откройте бота в Telegram, отправьте `/start`, затем загрузите короткое видео
или аудио с разборчивой речью.

Остановка:

```bash
docker compose down
```

Данные PostgreSQL сохраняются в volume `postgres_data`. Команда
`docker compose down -v` удалит этот volume и поэтому не должна использоваться,
если результаты нужно сохранить.

## Локальный запуск без Docker

Установите Python 3.12 и PostgreSQL, затем выполните:

```bash
python -m venv .venv
pip install -r requirements.txt
python bot.py
```

Для локального запуска укажите в `.env` строку подключения с `localhost`, например:

```env
DATABASE_URL=postgresql://meeting360:password@localhost:5432/meeting360
```

## Переменные окружения

| Переменная | Назначение |
|---|---|
| `TELEGRAM_BOT_TOKEN` | токен Telegram-бота |
| `ASSEMBLYAI_API_KEY` | ключ сервиса транскрибации |
| `OPENAI_API_KEY` | ключ для аудита встречи |
| `OPENAI_MODEL` | модель OpenAI |
| `ASSEMBLYAI_SPEECH_MODELS` | модели AssemblyAI через запятую |
| `MAX_FILE_SIZE_MB` | допустимый размер входного файла |
| `DATABASE_URL` | строка подключения при локальном запуске |
| `POSTGRES_DB`, `POSTGRES_USER`, `POSTGRES_PASSWORD` | настройки БД в Docker |

Никогда не добавляйте рабочий `.env` в Git. Он уже включён в `.gitignore`.

## Критерии аудита

Промпт проверяет: цель, повестку, фактический контекст, проблемы, варианты решения,
принятые решения, задачи, ответственных, сроки, риски и подтверждение итогов.
Каждый критерий получает 0–2 балла. Положительная оценка должна сопровождаться
короткой цитатой и тайм-кодом; если доказательств нет, бот пишет
«Не зафиксировано».

## Ограничения MVP

- качество разделения участников зависит от записи, фонового шума и пересечений речи;
- метки `Спикер A`, `Спикер B` не являются подтверждёнными именами людей;
- облачный Telegram Bot API ограничивает скачивание крупных файлов, поэтому лимит
  по умолчанию установлен в 20 МБ;
- реальный end-to-end тест требует действующих ключей трёх внешних сервисов;
- перед использованием с конфиденциальными встречами нужно определить срок хранения,
  правила доступа и порядок удаления данных.

## Структура проекта

| Файл | Назначение |
|---|---|
| `bot.py` | Telegram, транскрибация, AI-аудит и запись в БД |
| `prompt.md` | архитектура промпта и 11 критериев встречи |
| `docker-compose.yml` | бот, PostgreSQL, healthcheck и volume |
| `Dockerfile` | образ приложения |
| `.env.example` | безопасный шаблон настроек |
| `HOMEWORK_REPORT.md` | итоговый отчёт для сдачи задания |

## Проверка без внешних ключей

```bash
python -m compileall bot.py
python -m unittest discover -s tests -v
docker compose config
```

Полный тест считается успешным только после получения в Telegram двух результатов:
файла транскрипции и аудита по всем 11 критериям.
